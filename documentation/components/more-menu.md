
# MoreMenu

Цей компонент рендерить випадаюче меню, яке відкривається кнопкою з трьома крапками (`More`).

Побудований на основі `Radix UI Dropdown Menu` та дозволяє рендерити довільні дії через гнучкий API на основі render-функцій.

Меню автоматично керує:

- позиціонуванням;
- закриттям;
- контролем поширення подій.

Це робить його зручним для використання в:

- картках;
- елементах списків;
- таблицях;
- інших інтерактивних контейнерах.

## Props

| Prop                   | Значення за замовчуванням | Опис                                                 |
| ---------------------- | ------------------------- | ---------------------------------------------------- |
| `items`*               | —                         | Обов'язково. Масив пунктів меню                      |
| `className`            | `""`                      | Необов'язково. Додаткові класи кореневого контейнера |
| `triggerClassName`     | `""`                      | Необов'язково. Додаткові класи кнопки відкриття      |
| `menuWrapperClassName` | `""`                      | Необов'язково. Додаткові класи контейнера меню       |
| `side`                 | `bottom`                  | Необов'язково. Сторона, з якої відкривається меню    |
| `align`                | `end`                     | Необов'язково. Вирівнювання меню відносно кнопки     |

## MoreMenuItem

Кожен пункт меню описується такою структурою:

```ts
type MoreMenuItem = {
  id: string;
  content: (close: () => void) => ReactNode;
};
```

| Property   | Type                               | Description                                                               |
| ---------- | ---------------------------------- | ------------------------------------------------------------------------- |
| `id`*      | string                             | Обов'язково. Унікальний ідентифікатор, який використовується як React key |
| `content`* | `(close: () => void) => ReactNode` | Обов'язково. Функція, яка повертає вміст пункту меню                      |

## Функція close

Колбек `content` отримує функцію `close`, яку можна використати для програмного закриття меню.

```ts
{
  id: 'edit',
  content: (close) => (
    <button
      onClick={() => {
        handleEdit();
        close();
      }}
    >
      Edit
    </button>
  ),
}
```

## Можливості

- Побудований на основі `Radix UI Dropdown Menu`.
- Підтримує автоматичне визначення колізій (`avoidCollisions`).
- Запобігає поширенню кліків до батьківських елементів.
- Підтримує кастомний рендеринг пунктів меню.
- Підтримує програмне закриття меню.
- Рендерить контент через React Portal.

## Позиціонування

Положення меню можна налаштувати за допомогою пропсів `side` та `align`.

### side

| Значення | Опис                           |
| -------- | ------------------------------ |
| `top`    | Меню відкривається над кнопкою |
| `right`  | Меню відкривається праворуч    |
| `bottom` | Меню відкривається під кнопкою |
| `left`   | Меню відкривається ліворуч     |

### align

| Значення | Опис                        |
| -------- | --------------------------- |
| `start`  | Вирівнювання по початку     |
| `center` | Центрування відносно кнопки |
| `end`    | Вирівнювання по кінцю       |

## Стилізація

Стандартні стилі контенту меню:

```ts
rounded-lg bg-admin-more p-4 shadow-lg translate-y-3
```

Стандартні стилі кнопки відкриття:

```ts
px-2
```

Для розширення або перевизначення стилів використовуйте:

- `className`
- `triggerClassName`
- `menuWrapperClassName`

## Приклад використання

```tsx
<MoreMenu
  items={[
    {
      id: 'edit',
      content: (close) => (
        <button
          onClick={() => {
            handleEdit();
            close();
          }}
        >
          Edit
        </button>
      ),
    },
    {
      id: 'delete',
      content: (close) => (
        <button
          onClick={() => {
            handleDelete();
            close();
          }}
        >
          Delete
        </button>
      ),
    },
  ]}
/>
```

## Приклад з кастомним позиціонуванням

```tsx
<MoreMenu
  side="right"
  align="start"
  menuWrapperClassName="w-56"
  items={[
    {
      id: 'share',
      content: (close) => (
        <button
          onClick={() => {
            handleShare();
            close();
          }}
        >
          Share
        </button>
      ),
    },
  ]}
/>
```
