
# Slider

Цей React-компонент рендерить налаштовуваний слайдер (carousel) з підтримкою свайпів.

Компонент групує елементи у слайди та дозволяє навігацію за допомогою:

- свайпів (мобільні пристрої);
- кнопок зі стрілками;
- точок пагінації.

## Props

| Name            | Type                                      | Default | Description                                         |
| --------------- | ----------------------------------------- | ------- | --------------------------------------------------- |
| `items`*        | `T[]`                                     | -       | **Обов'язково.** Масив даних для відображення       |
| `renderItem`*   | `(item: T, index: number) => JSX.Element` | -       | **Обов'язково.** Функція рендерингу елемента        |
| `itemsPerSlide` | `number`                                  | `2`     | Необов'язково. Кількість елементів на одному слайді |
| `listClassName` | `string`                                  | `""`    | Необов'язково. Tailwind-класи для контейнера `<ul>` |
| `itemClassName` | `string`                                  | `""`    | Необов'язково. Tailwind-класи для контейнера `<li>` |

## Можливості

- **Swipe Support**

    Використовує хук `useSwipe` для навігації жестами:

    - `onSwipeLeft`
    - `onSwipeRight`

- **Pagination**

    Рендерить клікабельні точки пагінації для переходу між слайдами.

- **Navigation Buttons**

    Містить кнопки зі стрілками для ручної навігації.

### Transition

Використовує плавну анімацію переміщення:

```css
transition-transform duration-500
```

## Стилізація

- `overflow-hidden` — дозволяє відображати лише поточний слайд.
- `flex transition-transform` — створює ефект ковзання між слайдами.
- Кнопки та точки оновлюють свій стан відповідно до активного слайда.
- Неактивні кнопки мають зменшену прозорість та не реагують на наведення.

## Доступність

- Кнопки автоматично блокуються на першому та останньому слайдах.
- Точки пагінації підтримують навігацію з клавіатури.

## Об'єднання класів

Для об'єднання базових і кастомних класів використовується утиліта `cn`.

## Приклад використання

```typescript
<Slider
  items={reviews}
  itemsPerSlide={3}
  renderItem={(review, idx) => (
    <ReviewItem
      key={`${idx}-${review.id}`}
      review={review}
    />
  )}
  listClassName="flex-row"
/>
```
