# Slider

Цей React-компонент рендерить універсальний слайдер (carousel) з підтримкою свайпів та пагінації.

Компонент автоматично групує елементи у слайди та дозволяє навігацію між ними за допомогою:

* свайпів на мобільних пристроях;
* кнопок пагінації;
* клікабельних індикаторів сторінок.

Для відображення навігації використовується компонент `Pagination`.

## Props

| Prop                 | Значення за замовчуванням | Опис                                                      |
| -------------------- | ------------------------- | --------------------------------------------------------- |
| `items`*             | —                         | Обов'язково. Масив даних для відображення                 |
| `renderItem`*        | —                         | Обов'язково. Функція рендерингу окремого елемента         |
| `itemsPerSlide`      | `2`                       | Необов'язково. Кількість елементів на одному слайді       |
| `listClassName`      | `""`                      | Необов'язково. Додаткові класи для контейнера `<ul>`      |
| `itemClassName`      | `""`                      | Необов'язково. Додаткові класи для контейнера `<li>`      |
| `containerClassName` | `""`                      | Необов'язково. Додаткові класи для зовнішнього контейнера |
| `sliderClassName`    | `""`                      | Необов'язково. Додаткові класи для області слайдера       |
| `buttonsClassName`   | `""`                      | Необов'язково. Додаткові класи для компонента пагінації   |
| `showPagination`     | `true`                    | Необов'язково. Показувати або приховувати пагінацію       |

## Можливості

* Підтримка свайпів через хук `useSwipe`.
* Автоматичне групування елементів по слайдах.
* Плавна анімація перемикання.
* Інтеграція з компонентом `Pagination`.
* Підтримка будь-якого типу даних через Generic `<T>`.
* Гнучка стилізація всіх частин компонента.

## Swipe Navigation

Компонент підтримує:

* свайп вліво — перехід до наступного слайду;
* свайп вправо — перехід до попереднього слайду.

Навігація автоматично блокується на першому та останньому слайдах.

## Групування елементів

Елементи автоматично розбиваються на групи:

```tsx
itemsPerSlide={2}
```

Наприклад:

```tsx
items = [1, 2, 3, 4, 5]
```

створить:

```text
Слайд 1: [1, 2]
Слайд 2: [3, 4]
Слайд 3: [5]
```

## Стилізація

### Зовнішній контейнер

За замовчуванням:

```tsx
w-full mx-auto
```

Для кастомізації використовуйте:

```tsx
containerClassName
```

### Область слайдера

За замовчуванням:

```tsx
overflow-hidden
```

Для кастомізації використовуйте:

```tsx
sliderClassName
```

### Контейнер слайду

За замовчуванням:

```tsx
min-w-full flex flex-col
```

Для кастомізації використовуйте:

```tsx
listClassName
```

### Елемент слайду

За замовчуванням:

```tsx
p-2
```

Для кастомізації використовуйте:

```tsx
itemClassName
```

## Анімація

Перемикання між слайдами виконується через:

```tsx
transition-transform duration-500
```

та зміну:

```tsx
translateX(-${currentSlide * 100}%)
```

## Pagination

За замовчуванням пагінація увімкнена:

```tsx
showPagination={true}
```

Щоб приховати:

```tsx
<Slider
  showPagination={false}
  ...
/>
```

Для стилізації пагінації:

```tsx
buttonsClassName
```

## Приклад використання

```tsx
<Slider
  items={reviews}
  itemsPerSlide={3}
  renderItem={(review, index) => (
    <ReviewCard
      key={review.id}
      review={review}
    />
  )}
/>
```

## Приклад кастомізації

```tsx
<Slider
  items={projects}
  itemsPerSlide={1}
  containerClassName="max-w-4xl"
  sliderClassName="rounded-xl"
  listClassName="gap-4"
  itemClassName="p-0"
  buttonsClassName="mt-10"
/>
```

### Залежності

Компонент використовує:

* `useSwipe` — підтримка свайпів;
* `Pagination` — навігація між сторінками;
* `cn` — об'єднання CSS-класів.
