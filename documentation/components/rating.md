
# Rating

Цей React-компонент рендерить інтерфейс рейтингу із 5 зірок.

Підтримує два режими роботи:

- режим лише для перегляду (read-only);
- режим редагування, у якому користувач може змінювати оцінку.

## Props

| Name         | Type                       | Default     | Description                                                                         |
| ------------ | -------------------------- | ----------- | ----------------------------------------------------------------------------------- |
| `rating`*    | number                     | -           | Обов'язково. Поточне значення рейтингу від 1 до 5                                   |
| `isEditable` | boolean                    | `false`     | Необов'язково. Якщо `true`, користувач може змінювати рейтинг мишею або клавіатурою |
| `setRating`  | `(rating: number) => void` | `undefined` | Необов'язково. Функція для оновлення рейтингу                                       |
| `tabIndex`   | number                     | `0`         | Необов'язково. Значення tabindex для доступності                                    |
| `error`      | FieldError                 | `undefined` | Необов'язково. Об'єкт помилки валідації для відображення повідомлення та стилів     |
| `...props`   | React.HTMLAttributes       | -           | Додаткові пропси для контейнера `<ul>`                                              |

## Повна інтерактивність

- Зірки підсвічуються при наведенні курсора.
- Натискання на зірку змінює рейтинг (якщо передано `setRating`).
- Підтримується навігація клавіатурою (стрілки).
- Використовуються відповідні ARIA-атрибути для доступності.
- Якщо передано `error`, під рейтингом відображається повідомлення про помилку.

## Режим лише для перегляду

- Якщо `isEditable` відсутній або має значення `false`, рейтинг відображається статично.
- Будь-яка взаємодія та підтримка клавіатури відсутні.

## Особливості реалізації

- Компонент використовує внутрішній стан для відображення ефекту наведення без зміни основного значення рейтингу.

## Приклад використання

```tsx
// Просте відображення рейтингу
<Rating rating={4} />;

// Редагований рейтинг
const [rate, setRate] = useState(3);

<Rating
  rating={rate}
  isEditable={true}
  setRating={setRate}
  error={errors.rating}
/>;
```
