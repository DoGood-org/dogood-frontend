
# TaskFilter

Цей компонент рендерить випадаючий фільтр для списків завдань.

Він дозволяє користувачу вибрати один із попередньо визначених фільтрів та повідомляє батьківський компонент про зміну вибору.

Доступні фільтри залежать від ролі користувача.

Адміністратори та модератори мають інший набір фільтрів, ніж звичайні учасники.

## Props

| Prop        | Значення за замовчуванням | Опис                                                           |
| ----------- | ------------------------- | -------------------------------------------------------------- |
| `role`      | `undefined`               | Необов'язково. Роль користувача, яка визначає доступні фільтри |
| `onChange`* | —                         | Обов'язково. Викликається після вибору нового фільтра          |

## Поведінка

Компонент:

- відображає поточний вибраний фільтр;
- відкриває випадаюче меню після натискання;
- показує доступні фільтри залежно від ролі користувача;
- викликає `onChange()` при виборі нового фільтра;
- автоматично закриває меню після вибору;
- позначає активний фільтр іконкою галочки.

## Початковий стан

Після монтування компонент обирає:

```text
ALL
```

## Фільтри залежно від ролі

Набір доступних фільтрів визначається роллю користувача:

```tsx
const options =
  role === 'ADMIN' || role === 'MODERATOR'
    ? adminOptions
    : memberOptions;
```

## Адміністратор / Модератор

Використовує:

```text
adminOptions
```

## Учасник

Використовує:

```text
memberOptions
```

Точні значення визначені в:

```text
@/constants/taskFilterOptions
```

## Відображення вибраного значення

Поточний фільтр відображається всередині кнопки:

```tsx
t(`tasks.filter.${selected}`)
```

Завдяки цьому всі назви фільтрів можуть бути локалізовані через `next-intl`.

## Індикатор вибору

Поточний фільтр позначається іконкою галочки:

```tsx
{selected === option && <Check className="size-4" />}
```

## Приклад використання

```tsx
<TaskFilter
  role="MEMBER"
  onChange={(filter) => {
    setFilter(filter);
  }}
/>
```

Приклад для адміністратора:

```tsx
<TaskFilter
  role="ADMIN"
  onChange={(filter) => {
    loadTasks(filter);
  }}
/>
```

## Типові сценарії використання

- Списки завдань
- Панелі користувача
- Сторінки керування організацією
- Фільтрація волонтерської активності
- Адміністративне керування завданнями

## Залежності

Компонент використовує:

- `next-intl` — підтримка локалізації.
- `framer-motion` — анімації випадаючого меню.
- `CaretDown` — іконка відкриття меню.
- `Check` — індикатор вибраного пункту.
- `adminOptions` та `memberOptions` — доступні значення фільтрів.

## Примітки

- Компонент самостійно керує станом відкриття та закриття меню.
- Стан вибраного фільтра зберігається всередині компонента та передається назовні лише через `onChange`.
- Якщо батьківський компонент повинен повністю контролювати вибране значення, компонент слід переробити у керований (controlled component).
