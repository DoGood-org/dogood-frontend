
# MenuAction

Цей компонент рендерить пункт меню з іконкою та текстовою міткою.

Залежно від переданих пропсів він може рендерити:

- `Next.js Link` для навігації;
- `Button` для виконання дій через callback-функції.

Компонент забезпечує єдиний зовнішній вигляд для пунктів меню, які використовуються у:

- випадаючих меню;
- контекстних меню;
- панелях дій.

## Props

| Prop        | Значення за замовчуванням | Опис                                                                |
| ----------- | ------------------------- | ------------------------------------------------------------------- |
| `icon`*     | —                         | Обов'язково. React-компонент, який використовується як іконка       |
| `label`*    | —                         | Обов'язково. Текст, який відображається поруч з іконкою             |
| `href`      | `undefined`               | Необов'язково. URL для навігації. Якщо переданий — рендериться Link |
| `onClick`   | `undefined`               | Необов'язково. Callback, який викликається при натисканні           |
| `className` | `""`                      | Необов'язково. Додаткові класи для налаштування зовнішнього вигляду |

## Поведінка рендерингу

Компонент автоматично визначає, який елемент потрібно відобразити.

| Умова            | Рендериться |
| ---------------- | ----------- |
| Передано `href`  | `Link`      |
| `href` відсутній | `Button`    |

## Стилізація

Стандартні стилі для обох режимів рендерингу:

```tsx
flex gap-3 p-3
text-foreground
hover:text-btn-hover
active:text-btn-active
```

## Іконка

Іконка рендериться через компонент, переданий у пропсі `icon`.

Стандартна стилізація:

```tsx
<Icon className="size-5" />
```

Тому можна використовувати будь-яку іконку, яка підтримує проп `className`.

## Інтеграція з Button

Якщо `href` не переданий, компонент використовує спільний компонент `Button` з варіантом `ghost`.

```tsx
<Button variant="ghost">
  ...
</Button>
```

Це забезпечує візуальну узгодженість з іншими кнопками застосунку.

## Можливості

- Єдиний API для навігаційних та функціональних дій.
- Узгоджений стиль для пунктів меню.
- Працює з будь-якими компонентами іконок.
- Підтримує кастомну стилізацію через `className`.
- Використовує Next.js Link для клієнтської навігації.
- Повторно використовує проєктний компонент Button для дій без навігації.

## Приклад використання

### Навігаційна дія

```tsx
import { PencilSimple } from '@/components/icons';

<MenuAction
  icon={PencilSimple}
  label="Edit profile"
  href="/profile/edit"
/>
```

### Кнопка дії

```tsx
import { Trash } from '@/components/icons';

<MenuAction
  icon={Trash}
  label="Delete"
  onClick={handleDelete}
/>
```

### Дія з кастомною стилізацією

```tsx
<MenuAction
  icon={Archive}
  label="Archive"
  onClick={handleArchive}
  className="text-warning"
/>
```

## Примітки

Якщо одночасно передані `href` та `onClick`, спочатку буде виконано обробник кліку, а потім навігація.

Компонент часто використовується разом із `MoreMenu` для створення списків дій у випадаючих меню.

```tsx
<MoreMenu
  items={[
    {
      id: 'edit',
      content: (close) => (
        <MenuAction
          icon={PencilSimple}
          label="Edit"
          onClick={() => {
            handleEdit();
            close();
          }}
        />
      ),
    },
  ]}
/>
```
