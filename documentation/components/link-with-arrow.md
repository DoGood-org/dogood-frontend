
# LinkWithArrow

Цей React-компонент рендерить стилізоване посилання з іконкою стрілки вправо.

Побудований на основі компонента `Link` з Next.js та призначений для внутрішньої навігації в застосунку.

## Props
| Name        | Type            | Default                                            | Description                                                            |
| ----------- | --------------- | -------------------------------------------------- | ---------------------------------------------------------------------- |
| `href`*     | string          | -                                                  | Обов'язково. URL або маршрут переходу (наприклад `/about`, `/contact`) |
| `text`*     | string          | -                                                  | Обов'язково. Текст посилання                                           |
| `className` | string          | ""                                                 | Необов'язково. Додаткові Tailwind-класи                                |
| `icon`      | React.ReactNode | `<ArrowRight className="stroke-current size-6" />` | Необов'язково. Дозволяє замінити стандартну іконку                     |
| `onClick`   | `() => void;`   |                                                    | Необов'язково. Обробник кліку                                          |


## Стилізація

* `text-base` — базовий стиль тексту.
* `hover:text-btn-hover, focus:text-btn-hover, active:text-btn-active` — зміна кольору при взаємодії.
* `flex items-center gap-2` — горизонтальне вирівнювання тексту та іконки.

## Іконка стрілки

* Використовує компонент `ArrowRight` за замовчуванням.
* Для заміни використовуйте проп `icon`.
* Наслідує колір тексту через `stroke-current`.
* Має розмір `size-6`.

## Об'єднання класів

Використовує утиліту `cn` для безпечного об'єднання базових і користувацьких класів.

## Приклад використання

```tsx
<LinkWithArrow
  href={`/${locale}/about`}
  text={t('aboutButton')}
  className="mt-auto"
/>
```
