
# Container

Цей компонент рендерить `div`, який центрує контент та обмежує його ширину відповідно до адаптивних брейкпоінтів.

Також він застосовує горизонтальні відступи, що адаптуються до розміру екрана.

Для розширення або перевизначення стилів можна використовувати проп `className`.

## Props
| Prop        | Значення за замовчуванням | Опис                                                  |
| ----------- | ------------------------- | ----------------------------------------------------- |
| `children`* | —                         | Обов'язково. Контент, який буде обгорнуто контейнером |
| `className` | `my-container`            | Необов'язково. Додаткові CSS-класи для контейнера     |


## Адаптивні брейкпоінти (CSS-змінні)

Ширина контейнера обмежується такими брейкпоінтами:

| Breakpoint | Назва змінної   | Ширина | Горизонтальні відступи |
| ---------- | --------------- | ------ | ---------------------- |
| sm         | --breakpoint-sm | 393px  | 20px                   |
| md         | --breakpoint-md | 768px  | 60px                   |
| lg         | --breakpoint-lg | 1440px | 80px                   |
| xl         | --breakpoint-xl | 1920px | 80px                   |

## Застосовані стилі

Клас `.my-container` використовує утиліти Tailwind та CSS-змінні:

```css
.my-container {
  @apply w-full mx-auto px-5;
  @apply sm:px-5 sm:max-w-[var(--breakpoint-sm)];
  @apply md:px-15 md:max-w-[var(--breakpoint-md)];
  @apply lg:px-20 lg:max-w-[var(--breakpoint-lg)];
  @apply xl:px-20 xl:max-w-[var(--breakpoint-xl)];
}
```

✅ Пояснення:

* `w-full` — контейнер займає всю доступну ширину.
* `mx-auto` — контейнер центрується по горизонталі.
* `px-*` — горизонтальні відступи змінюються залежно від брейкпоінта.
* `max-w-*` — максимальна ширина обмежується відповідною CSS-змінною.

## Приклад використання

```tsx
<Container className="bg-gray-100">
  <p>Цей контент відцентрований та адаптивний.</p>
</Container>
```

## Примітки

* Контейнер допомагає утримувати контент у межах комфортної ширини на великих екранах та забезпечує відповідні відступи на малих.

* Якщо потрібно перевизначити відступи або максимальну ширину, передайте власні utility-класи через `className`.
