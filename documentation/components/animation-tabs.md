# AnimationTabs

Цей React-компонент рендерить анімований перемикач вкладок (tabs).

Він призначений для використання на сторінках профілю або акаунта, де користувач може перемикатися між різними представленнями контенту (наприклад: Tasks, Organization, Reviews).

Компонент підтримує:

- свайпи на мобільних пристроях;
- анімоване підкреслення активної вкладки;
- опціональне горизонтальне прокручування.

## Props

| Name          | Type                     | Default | Description                                                                   |
| ------------- | ------------------------ | ------- | ----------------------------------------------------------------------------- |
| `views`*      | `{ view: string }[]`     | —       | Обов'язково. Масив об'єктів вкладок. Кожен об'єкт повинен містити поле `view` |
| `activeView`* | string                   | —       | Обов'язково. Поточна активна вкладка                                          |
| `onChange`*   | `(view: string) => void` | —       | Обов'язково. Викликається при виборі або свайпі на іншу вкладку               |
| `isScroll`    | boolean                  | `false` | Необов'язково. Увімкнути горизонтальне прокручування на мобільних пристроях   |
| `buttonClass` | string                   | `""`    | Необов'язково. Додаткові Tailwind-класи для кнопок вкладок                    |
| `refClass`    | string                   | `""`    | Необов'язково. Додаткові класи для контейнера кнопок                          |
| `headClass`   | string                   | `""`    | Необов'язково. Класи для зовнішнього контейнера компонента                    |

## Поведінка

- На мобільних пристроях при `isScroll: true` вкладки стають горизонтально прокручуваними та підтримують свайпи.

- Свайп вліво активує наступну вкладку.

- Активна вкладка виділяється анімованим підкресленням через `motion.div`.

- На мобільних пристроях може відображатися додаткова кнопка переходу до наступної вкладки (`CaretDoubleRight`).

## Взаємодія

- Натискання на вкладку викликає `onChange(view)`.

- Свайп вліво переходить до наступної вкладки (лише якщо `isScroll === true`).

- На планшетах та десктопах (`min-width: 768px`) усі вкладки відображаються статично без прокручування та свайпів.

## Залежності

Використовуються:

- `framer-motion` — для анімації підкреслення активної вкладки.

Кастомні хуки:

- `useMediaQuery` — визначення розміру екрана.
- `useScrollToActive` — прокручування до активної вкладки.
- `useSwipe` — обробка свайпів.

## Приклад використання

```tsx
<AnimationTabs
  views={[
    { view: 'Tasks' },
    { view: 'Organization' },
    { view: 'Reviews' },
  ]}
  activeView={activeView}
  onChange={setActiveView}
  isScroll={true}
  buttonClass="p-3"
  refClass="gap-2"
  headClass="mb-4"
/>
```
