
# Section

Цей компонент рендерить HTML-елемент `section` зі стандартними верхніми та нижніми відступами.

Він обгортає свій вміст у компонент `Container`, щоб відцентрувати контент та обмежити його ширину.

Ви можете розширити або перевизначити стилі через проп `className`.

## Props
| Prop            | Значення за замовчуванням | Опис                                                                                     |
| --------------- | ------------------------- | ---------------------------------------------------------------------------------------- |
| `children`*     | `undefined`               | Обов'язково. Будь-який текстовий або React-контент                                       |
| `className`     | `py-[30px] xl:py-[50px]`  | Необов'язково. Додаткові CSS-класи для розширення або перевизначення стилів              |
| `withContainer` | `true`                    | Необов'язково. Обгортає дочірні елементи в `Container`. Встановіть `false`, щоб вимкнути |


## Примітки

* Компонент додає вертикальні відступи:

  * `30px` на малих екранах;
  * `50px` на екранах `xl` і більших.

* Як `children` можна передавати будь-які валідні React-вузли, а не лише текст.

* Переданий `className` буде додано до стандартних класів відступів. Якщо потрібно перевизначити відступи, додайте власні класи відступів у `className`.

## Приклад використання

```tsx
// Стандартне використання (з Container)
<Section className="bg-gray-100">
  <h2>Всередині контейнера</h2>
</Section>

// Без Container
<Section withContainer="{false}" className="bg-gray-100">
  <h2>Без контейнера</h2>
</Section>
```
