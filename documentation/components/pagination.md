
# Pagination

Цей React-компонент рендерить навігацію між сторінками або слайдами.

Компонент використовується в `Slider`, але може застосовуватись і самостійно для будь-якої пагінації, де потрібно перемикатися між сторінками за допомогою кнопок та індикаторів.

## Props


| Prop            | Значення за замовчуванням | Опис                                                    |
| --------------- | ------------------------- | ------------------------------------------------------- |
| `currentPage`*  | —                         | Обов'язково. Поточна активна сторінка (індексація з 0)  |
| `totalPages`*   | —                         | Обов'язково. Загальна кількість сторінок                |
| `onPageChange`* | —                         | Обов'язково. Викликається при зміні сторінки            |
| `className`     | `""`                      | Необов'язково. Додаткові класи для контейнера пагінації |


## Можливості

* Кнопка переходу на попередню сторінку.
* Кнопка переходу на наступну сторінку.
* Клікабельні індикатори сторінок.
* Автоматичне блокування кнопок на межах.
* Автоматичне приховування при одній сторінці.

## Автоматичне приховування

Якщо доступна лише одна сторінка:

```tsx
totalPages <= 1
```

компонент нічого не рендерить.

## Навігаційні кнопки

### Попередня сторінка

Викликає:

```tsx
onPageChange(currentPage - 1)
```

Кнопка автоматично блокується на першій сторінці.

### Наступна сторінка

Викликає:

```tsx
onPageChange(currentPage + 1)
```

Кнопка автоматично блокується на останній сторінці.

## Індикатори сторінок

Для кожної сторінки створюється окрема кнопка.

Активна сторінка відображається заповненим кружечком:

```tsx
bg-foreground
```

Неактивна сторінка:

```tsx
border-foreground
```

## Стилізація

### Контейнер

За замовчуванням:

```tsx
flex items-center justify-center gap-4 mt-6
```

### Контейнер індикаторів

За замовчуванням:

```tsx
flex items-center gap-[18px]
```

### Стрілки

Активний стан:

```tsx
hover:scale-110 cursor-pointer
```

Неактивний стан:

```tsx
opacity-30 cursor-auto
```

## Іконки

Використовуються:

```tsx
<ChevronLeft />
<ChevronRight />
```

зі стандартними стилями:

```tsx
w-5 h-5 text-foreground
```

## Приклад використання

```tsx
const [page, setPage] = useState(0);

<Pagination
  currentPage={page}
  totalPages={5}
  onPageChange={setPage}
/>
```

### Приклад кастомізації

```tsx
<Pagination
  currentPage={page}
  totalPages={10}
  onPageChange={setPage}
  className="mt-12"
/>
```

### Типові сценарії використання

* Слайдери
* Каруселі
* Галереї
* Покрокові форми
* Пагінація списків
* Пагінація карток

### Залежності

Компонент використовує:

* `ChevronLeft`
* `ChevronRight`
